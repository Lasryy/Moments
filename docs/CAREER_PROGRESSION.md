# Progression de carrière

Les profils de base couvrent la progression régulière, le prodige précoce, l'explosion tardive, l'exponentielle, le pic de deux ou trois saisons, le déclin précoce, l'éternel espoir, la stabilité, la renaissance, la trajectoire chaotique, la longévité exceptionnelle et l'effondrement sportif. Ils orientent les probabilités, sans décider du destin.

L'âge, le potentiel, la forme, le temps de jeu, la confiance, les blessures, le professionnalisme, le contexte du club et les performances dans les Moments modifient la courbe. À terme, les attributs pourront décliner, les joueurs apprendre ou perdre un poste, et un changement de position offrira parfois une seconde vie.
